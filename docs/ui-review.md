# ผลตรวจการใช้งานและการเชื่อมโมเดล

ตรวจวันที่ 18 ตุลาคม 2026 บน Edge แบบ headless ทั้งหน้าจอคอมและขนาดมือถือ รวม 320 px พร้อม Light/Dark Mode

ปัญหาที่พบและแก้แล้ว:

- metadata จริงของ mZNDylZHP ใช้ชื่อย่อลงท้าย `...` 4 หมวด ทำให้โหลดโมเดลไม่ผ่าน เพิ่ม alias ตรงตัวครบทั้ง 4 และคงการตรวจชื่อซ้ำ ชื่อขาด และข้อจำกัด Photo transistor ไว้
- ภาพ breadboard กว้าง 1000 หน่วยถูกย่อทั้งบอร์ดบนมือถือ 390 px ทำให้ข้อความป้ายจุดต่อเหลือประมาณ 5.65 px เปลี่ยนเป็นขยายเฉพาะสายและอุปกรณ์ที่เกี่ยวข้อง ป้ายของกรณีทดสอบ Transistor สายที่ 3 เพิ่มเป็นประมาณ 15.5 px มีปุ่มแสดงทั้งบอร์ดกลับได้
- ภาพขยายเดิมบังคับกว้าง 1000 px ในพื้นที่ 324 px และไม่มีปุ่มเปลี่ยนสาย เปลี่ยนเป็นพอดีหน้าจอ พร้อมเลือกสาย ดูทุกสาย ย่อ/ขยาย และกลับพอดีหน้าจอได้ในหน้าต่างเดียว
- เปิดภาพขยายจากหน้าสแกนแล้วพื้นหลังยังเลื่อนได้ เพิ่ม scroll lock และคืนค่าถูกต้องเมื่อปิด รวมกรณีหน้าต่างรายละเอียดซ้อนกัน
- ปุ่มที่เลือกในโหมดมืดมีข้อความขาวบนพื้นฟ้าสว่าง ปรับเป็นฟ้าเข้มเพื่ออ่านชัดขึ้น
- คำแนะนำในโหมดภาพจุดต่อสายเคยบอกให้ดูป้ายสีเขียว/ส้ม ทั้งที่ป้ายเหล่านี้อยู่ในภาพ breadboard แก้ข้อความตามโหมดและการเลือกดูทุกสาย
- คะแนนจริง 70.001% ผ่านเกณฑ์แต่เดิมแสดง 70.0% เปลี่ยนเป็น `>70.0%` โดยยังใช้ค่าจริงและปฏิเสธคะแนนไม่เกิน 70% เหมือนเดิม

การตรวจที่ผ่าน:

- Unit tests 19/19: ชื่อคลาสจริงและชื่อย่อ ความมั่นใจ การเชื่อมต่อทั้ง 16 ตัวอย่าง และตรวจว่าภาพที่ขยายไม่ตัดป้ายจุดต่อ สาย หรืออุปกรณ์ที่เกี่ยวข้อง
- Browser suite 50/50 หลังแก้ UI; ตรวจชุด AI ซ้ำ 14/14 หลังเพิ่ม alias และแก้การแสดงคะแนนใกล้เกณฑ์
- โมเดลจริงโหลดสำเร็จ 14 outputs; กด Analyze ซ้ำ 2 ครั้ง; โหลด model.json ครั้งเดียว; ไม่มี POST ภาพออกจากเบราว์เซอร์
- Production build และ git diff --check ผ่าน

ข้อจำกัดที่ยังพบในโมเดล:

- ภาพพื้นสีเทาล้วน 224×224 ซึ่งไม่มีอุปกรณ์ ยังได้ Thermistor ประมาณ 98.4% ใน runtime smoke test นี้ การตั้งเกณฑ์ 70% จึงไม่ได้รับประกันว่าภาพนอกกลุ่มจะถูกปฏิเสธ ควรฝึกด้วยตัวอย่างภาพที่ไม่ใช่อุปกรณ์หรือเพิ่มตัวตรวจภาพนอกกลุ่ม และวัดผลด้วยชุดภาพจริงที่มีเฉลยก่อนรับรองความแม่นยำ
- หมวด phototransistor ฝึกเฉพาะ Photo transistor ตามข้อมูลที่ผู้ใช้ยืนยัน ไม่รองรับการจำแนก IR LED การเพิ่ม alias ไม่ได้เพิ่มความสามารถของโมเดล
- ภาพ breadboard แสดงตัวอย่างการจัดวางตามชื่อขา ยังไม่ได้ทดสอบต่อวงจรกับอุปกรณ์จริงทุกเบอร์ ต้องเทียบ datasheet และพิกัดของชิ้นงานจริง

`scripts/review-ui.mjs` ใช้สร้างภาพหน้าจอและค่าขนาดข้อความซ้ำกับ dev server ที่พอร์ต 5204 ผลอยู่ใน `test-results/ui-review/` การทดสอบภาพสังเคราะห์ตรวจ runtime และการเชื่อมต่อ ไม่ใช่การวัด accuracy
